# Гид: локальный запуск и тестирование lip-dictation

Ниже `<папка>` — абсолютный путь к этой папке `lip-dictation`.

## Что проверено

- Мод проходит `claude plugin validate` и проверку типов TypeScript, тесты интерфейса (`claude plugin test <папка>`) идут с поддельным Python-процессом: запись, вставка текста, заранее загруженная диктовка, обучение, настройки, история.
- Вживую на Mac с Apple Silicon: установка, запрос доступа к камере в Claude Desktop, диктовка, обучение на своих фразах. Переключение личной модели проверено на уровне сайдкара (`lipread.sh --personal on|off`).
- Энкодер на GPU (`--device auto` выбирает mps) даёт те же тексты, что на CPU.

Не проверено: установка на чистой машине (самые хрупкие места — `mediapipe==0.10.21` под Python 3.12 и скачивание весов с Google Drive), Intel Mac, Linux (не поддерживается: хелпер для камеры только для macOS).

## Шаг 0. Подготовка (интернет почти не нужен)

```bash
brew install uv
```

Плагин можно поставить сразу, без моделей: над полем ввода появится кнопка **👄 Set up lip dictation**. Без Wi-Fi её не нажимай.

```bash
claude plugin marketplace add "<папка>"
```

```bash
claude plugin install lip-dictation@lip-dictation
```

Плагин из локального маркетплейса читается **прямо из папки**. После правок кода достаточно выполнить `/reload-plugins` в сессии, переустанавливать не нужно.

Альтернатива для разработки — разовый запуск без установки:

```bash
claude --plugin-dir "<папка>"
```

После установки из терминала плагин появляется и во вкладке Code в Claude Desktop.

## Шаг 1. Установка моделей (только на Wi-Fi, около 1,5 ГБ трафика)

В Claude Code нажми **👄 Set up lip dictation** или выполни `/lip-setup`. Сначала появится вопрос с размером загрузки и условиями лицензии модели, скачивание начнётся только после «Install». Прогресс в строке статуса. Или в терминале:

```bash
"<папка>/scripts/setup.sh"
```

Над полем ввода видна полоса прогресса: текущий шаг, а на шаге загрузки модели — проценты. Скрипт делает четыре шага (повторный запуск пропускает готовые):
1. Создаёт Python-окружение `~/.cache/lip-dictation/venv`: torch, mediapipe, opencv и др.
2. Делает частичный `git clone` кода auto_avsr на закреплённом коммите, только нужные для распознавания файлы.
3. Скачивает веса `vsr_trlrs2lrs3vox2avsp_base.pth` (~1 ГБ) с Google Drive, проверяет, что это не HTML-страница, и сверяет MD5 и SHA-256. При ошибке недокачанный файл удаляется.
4. Собирает из `scripts/camera-app` маленькое приложение `~/.cache/lip-dictation/Lip Dictation.app` (нужны Xcode Command Line Tools). Python запускается через него, и разрешение на камеру macOS спрашивает для «Lip Dictation».

Лог установки: `~/.cache/lip-dictation/setup.log`.

Если Google Drive отдаст HTML вместо файла (так бывает при лимитах), setup так и скажет. Тогда скачай модель вручную по ссылке из [README auto_avsr](https://github.com/mpc001/auto_avsr#model-zoo) в `~/.cache/lip-dictation/models/` и перезапусти setup.

## Шаг 2. Проверка без Claude Code

```bash
"<папка>/scripts/lipread.sh" check --camera
```

Должно вывести `OK model loads`, `OK camera` и `Ready.`. При первом доступе macOS спросит разрешение на камеру для «Lip Dictation». Если отказал — «Системные настройки → Конфиденциальность и безопасность → Камера».

Тест распознавания с сохранением записи (запись остановится, когда появится стоп-файл):

```bash
"<папка>/scripts/lipread.sh" dictate --stop-file /tmp/lip-stop --save /tmp/lip-take1.mp4
```

Беззвучно проговори фразу, затем в другой вкладке терминала:

```bash
touch /tmp/lip-stop
```

В ответ придут JSON-события: `recording` → `processing` → `result`. Сохранённое видео можно прогнать повторно, например с другими настройками:

```bash
"<папка>/scripts/lipread.sh" --beam-size 20 file /tmp/lip-take1.mp4
```

Совет для оценки точности: запиши 10–20 типичных фраз, которые ты реально пишешь Claude, и посчитай, сколько слов распознано верно.

## Шаг 3. Проверка в Claude Code

1. Открой новую сессию (или `/reload-plugins`).
2. Нажми кнопку **👄 Lip dictation** над полем ввода.
3. Когда появится строка **■ Stop ● 0:03 ▁▁▃▆█▅▂▁▁**, проговаривай фразу. Таймер идёт вверх, волна показывает движение губ: столбики растут снизу, когда рот двигается, и опускаются в ровную линию, когда он неподвижен, и предупреждение «face not in view», если лицо ушло из кадра. Через 20 секунд запись остановится сама, последние 5 секунд идёт обратный отсчёт.
4. Нажми **■ Stop**. Пока идёт распознавание, видна полоса «Reading lips», потом текст появится там, где стоит курсор, не отправленный.
5. Отправь промпт. Claude получит скрытую заметку: какие слова прочитаны по губам и что перед разрушительными действиями нужно переспросить.

Команда `/lip` тоже работает, но набранная в поле ввода она заменяет черновик. Чтобы дописать к уже набранному тексту, используй кнопку или горячую клавишу. Если в момент вставки открыт диалог, текст скопируется в буфер обмена.

В терминале кнопку можно сфокусировать через `ctrl+x`, затем `tab`, после чего её нажимает клавиша `l`. В десктопном приложении у плашки нет фокуса с клавиатуры, поэтому подсказка `l` там не показывается. Удобнее назначить свою клавишу в `~/.claude/keybindings.json`:

```json
{ "bindings": [{ "context": "Chat", "bindings": { "meta+l": "command:lip" } }] }
```

`meta+l` сработает, только если в Terminal.app или iTerm2 включено «Use Option as Meta key»; иначе Option+L печатает «¬». Можно выбрать любое свободное сочетание.

Разрешение на камеру и в терминале, и в Claude Desktop выдаётся приложению «Lip Dictation». Без него в Claude Desktop камера не работала бы вовсе: Claude Code там запускается как отдельное приложение, в котором камера не объявлена, и macOS отказывает молча, без запроса. Поэтому `lipread.sh` запускает Python через `Lip Dictation.app`, а тот снимает с себя ответственность родителя (как `disclaimer` в Claude Desktop) и становится «ответственным» приложением сам.

## Шаг 4. Подстройка под свои губы

Модель обучали на людях, которые говорят вслух. Беззвучно губы двигаются меньше, поэтому на тебе она ошибается чаще. Подстройка:

1. Нажми **⚙ Settings → 🎯 Train on my lips** или выполни `/lip-train`. На плашке появится фраза, например «run the tests», с обычными **■ Stop** и волной. Проговори её и нажми Stop. Сохраняется только область рта 96×96 пикселей в `~/.cache/lip-dictation/personal/`.
2. **● Next phrase** — следующая фраза. Кнопка **Train** появится после 20 фраз, лучше записать около 100 (10–15 минут). **Done** — пауза, следующий `/lip-train` продолжит с того же места. Список фраз (`sidecar/lipread/phrases.txt`) — бытовые фразы вперемешку с просьбами к ассистенту, его можно дополнить своими.
3. Нажми **Train**. Обучение идёт несколько минут (около секунды на фразу за проход, 8 проходов). Модель получает небольшие LoRA-адаптеры (около 2 млн параметров) только в энкодере, который читает губы. Декодер, по сути языковую модель, обучение не трогает: иначе после нескольких десятков фраз о коде он начинает подставлять их слова в любой текст. Каждая пятая фраза отложена для проверки: до и после считается доля ошибочных слов (WER), тост покажет оба числа. Личная модель включается, только если ошибок стало меньше.

После обучения в **⚙ Settings** появляется **🧠 Personal model: On**: нажатие выключает личную модель (**Off**, диктовка идёт стоковой) и включает обратно. Удобно сравнивать обе по истории. Новое обучение включает модель само.

Кроме того, к каждой диктовке Claude получает другие варианты прочтения из beam search: правильные слова часто среди них.

## История диктовок

**⚙ Settings → 🕘 History** открывает панель с последними диктовками, новые сверху: вставленный текст, другие варианты, которые рассматривала модель, длина записи, время распознавания, стоковая или личная модель, и как ты отправил текст — как есть (✓) или поправив (✎, с отправленным промптом). По ней видно, где модель ошибается. Те же данные лежат в `~/.cache/lip-dictation/dictations.jsonl` по строке JSON на диктовку или отправку, их печатает `"<папка>/scripts/lipread.sh" --history`.

**⚙ Settings → 🗑 Delete my data** (или `"<папка>/scripts/lipread.sh" forget`) удаляет записанные фразы, личную модель и историю.

## Как это устроено

| Файл | Роль |
|---|---|
| `hooks/register.tsx` | Мод: команды `/lip`, `/lip-setup`, кнопка над полем ввода, вставка текста (`$.prompt.fill`), заметка для Claude (`prompt.submit`). |
| `scripts/lipread.sh` | Запускает Python из `~/.cache/lip-dictation/venv` через `Lip Dictation.app`. Ничего не скачивает. |
| `scripts/setup.sh` | Одноразовая установка окружения, кода auto_avsr и весов, сборка `Lip Dictation.app`. |
| `scripts/camera-app/` | Лаунчер и `Info.plist` приложения «Lip Dictation», которому macOS выдаёт доступ к камере. |
| `sidecar/lipread/camera.py` | Запись с камеры до стоп-файла, пересэмплинг в 25 fps (как в обучении модели), уровень движения губ для волны (`MouthMeter`). |
| `tests/band.test.tsx` | Тесты интерфейса с поддельным Python-процессом. |
| `sidecar/lipread/model.py` | mediapipe → вырезка рта → Auto-AVSR → beam search → текст и другие варианты; подмешивает личный адаптер. |
| `sidecar/lipread/personal.py` | Фразы для `/lip-train`, их хранение, обучение LoRA-адаптера, замер WER. |
| `sidecar/lipread/phrases.txt` | Фразы для подстройки. |
| `sidecar/lipread/__main__.py` | CLI: `dictate`, `enroll`, `train` (JSON-события для мода), `forget`, `file`, `check`. |

Остановка записи работает через файл: мод не может писать в stdin уже запущенного процесса. Python первым событием сообщает путь к временному стоп-файлу, второе нажатие создаёт этот файл, а Python проверяет его на каждом кадре.

## Если что-то не работает

- **`uv sync` падает на mediapipe.** Нужен Python 3.12, setup его запрашивает. Если колёс нет, попробуй другую версию 0.10.x, в которой ещё есть `mp.solutions` (до 0.10.21 включительно точно есть).
- **Волна почти не поднимается при беззвучной речи.** Пороги в `MouthMeter` (`sidecar/lipread/camera.py`) подобраны на глаз: уменьши `0.04` и `0.35` или увеличь множитель `6` у скорости движения.
- **«No face found».** Сядь прямо перед камерой, лицо должно быть хорошо освещено.
- **«Recording was too short».** Минимум 1 секунда.
- **Медленно.** Первая диктовка в сессии загружает Python и модель (около 2 с до включения камеры). После неё мод заранее запускает следующую диктовку в режиме ожидания (`dictate --wait`, около 1 ГБ памяти, до 10 минут), и следующее нажатие сразу включает камеру. Можно ещё уменьшить `--beam-size` (по умолчанию 10). `LIPREAD_DEVICE=cpu` вернёт энкодер на CPU.
- **«Your face is not centered».** Модель вырезает область рта, лицо должно быть в центре кадра.
- **Установка застряла с ошибкой «another setup is running».** Если установка точно не идёт, удали папку `~/.cache/lip-dictation/.setup.lock`.
- **Кнопки не видно.** Проверь `claude plugin list` и включён ли `showButton` в `/config`. Ошибки модов видны в `claude --debug`.
